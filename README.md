# 🐍 Cobra Neon - Edição Profissional

Um jogo da cobra moderno e profissional com UI de nível AAA, desenvolvido com React, TypeScript e Tailwind CSS.

## ✨ Características Profissionais

### 🎮 Jogabilidade Aprimorada
- **Sistema de Combo**: Colete maçãs rapidamente para multiplicar seus pontos (até 5x)
- **Velocidade Progressiva**: O jogo acelera conforme você cresce
- **Controles Responsivos**: Suporte para setas e WASD
- **Sistema de Pausa**: Pressione ESPAÇO a qualquer momento

### 🎨 UI de Nível AAA
- **Design Neon Futurista**: Gradientes vibrantes e efeitos de brilho
- **Animações Suaves**: Transições fluidas e efeitos de partículas
- **Efeitos Visuais**:
  - Partículas explosivas ao coletar comida
  - Indicador de combo animado
  - Brilho neon pulsante
  - Sombras e profundidade 3D
  - Animações de entrada/saída
- **Cobra Detalhada**: Cabeça com olhos animados, corpo com gradiente e cauda arredondada
- **HUD Profissional**: Placar com pontos, recorde e velocidade em tempo real

### 🎵 Áudio
- Efeitos sonoros ao coletar comida
- Som de game over
- Pitch dinâmico baseado no combo

### 📊 Sistema de Pontuação
- Pontuação salva localmente
- Recorde persistente
- Multiplicador de combo
- Estatísticas detalhadas no game over

## 🚀 Como Jogar

### Controles
- **↑ ↓ ← →** ou **W A S D**: Mover a cobra
- **ESPAÇO**: Pausar/Continuar
- **ENTER**: Iniciar jogo

### Objetivo
Colete o máximo de maçãs possível sem colidir com as paredes ou com seu próprio corpo. Mantenha um combo alto para multiplicar seus pontos!

## 🛠️ Tecnologias

- **React 19** - Framework UI
- **TypeScript** - Type safety
- **Tailwind CSS** - Estilização
- **Vite** - Build tool
- **HTML5 Audio API** - Efeitos sonoros

## 💻 Executar Localmente

**Pré-requisitos:** Node.js 16+

1. Instalar dependências:
   ```bash
   npm install
   ```

2. Executar em modo desenvolvimento:
   ```bash
   npm run dev
   ```

3. Build para produção:
   ```bash
   npm run build
   ```
